# Bug Finder
So this is my first time using Python to create a CLI game; my original plan was to use Rust, but it was too hard, so I switched to Python. You may find out in the Rust branch.


## How to play?
So, you need to download the executable file from the GitHub Release. Then run it!
> Or using uv pip: `pip install bugfinder==1.0.6` then `uv run python -m bugfinder`


- WASD to move
- E to Talk
- Space to continue to the next dialog

The demo has 3 levels plus an intro room and an end room.
